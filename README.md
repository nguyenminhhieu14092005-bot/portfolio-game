# Portfolio Nguyễn Minh Hiếu 2026 · phiên bản game 3D

Portfolio dạng game khám phá cốt truyện: đi cùng nhân vật Híu qua 8 chương, từ Làng Tân Thủ đến Sảnh Tuyển Dụng.

- Chơi trực tiếp trên trình duyệt, không cần cài đặt.
- Điều khiển: WASD hoặc bấm mặt đất để đi, E trò chuyện, Space lướt. Khi gặp Mông Lung: giữ chuột trái hoặc J để bắn, K dùng kỹ năng Đo Lường.
- Không muốn chơi: bấm "Xem hồ sơ ngay" ở màn hình đầu.

Toàn bộ game nằm trong một file `index.html`.
