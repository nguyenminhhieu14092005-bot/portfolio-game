# Portfolio Nguyễn Minh Hiếu 2026 · phiên bản game 3D

Portfolio dạng game khám phá cốt truyện: đi cùng nhân vật Híu qua 8 chương, từ Làng Tân Thủ đến Sảnh Tuyển Dụng. Từ bản 2.0, game không còn chiến đấu: ở mỗi cổng, Mông Lung hiện ra và một thước phim ngắn kể cách Híu vượt qua giai đoạn đó.

- Chơi trực tiếp trên trình duyệt, không cần cài đặt, khoảng 6-9 phút.
- Điều khiển: WASD hoặc bấm mặt đất để đi, giữ Shift để chạy nhanh, E trò chuyện. Trên điện thoại: cần điều khiển và nút Chạy.
- Thước phim: bấm hoặc Space để sang cảnh tiếp, giữ để tua nhanh, P tạm dừng, nút Bỏ qua để mở cổng ngay.
- Không muốn chơi: bấm "Xem hồ sơ ngay" hoặc "Mở nhanh toàn bộ bản đồ" ở màn hình đầu.

Toàn bộ game nằm trong một file `index.html`.
